# VegaKT 残差・計算方式の監査 v0.1

日付: 2026-10-02  
状態: 残差の原因確認は合格。論文方式の数値受入は未合格。

## 今回の修正

前回の[数値検証](vega-kt-backtest-numerics-v0.1.md)では、格子幅による倍率の誤りを修正しました。
今回は、残差を `local_parallel_vega - bucket_sum` で作る処理を廃止し、実際に除外した感応度を別途集計する方式に変更しました。

- 初期時刻 `T=0` のローカル感応度を保持する。
- 正の時刻で密度閾値の対象外となった符号付き感応度を保持する。
- 格子端に配賦した感応度と件数を、各時刻から集計する。
- 反対符号の乱数を組み合わせる際は感応度を平均し、件数は実際の経路数で数える。
- RQMCではまず各スクランブル内で平均し、その後スクランブル間で平均する。
- 算出済みバケット、除外感応度、配賦前合計が一致しなければエラーにする。

通常のMC/RQMCと、行使方針を固定した早期行使の両方に適用しています。
レポート生成処理も共通化しました。意図的にバケットを壊す回帰テストで、合計が整っているように見せずエラーにできることを確認しています。

現在の処理はローカル感応度の配賦であり、論文のガンマ復元・伝播はまだ接続されていません。
そのためネイティブ結果の方式名を次のように修正しました。

| 項目 | 新しい出力 |
| --- | --- |
| `policy_label` | `local_vol_node_allocation_diagnostic_v1` |
| `truncation_order` | `not_applicable` |
| バックテストの各銘柄 | `Risk.native_policy` に実際の方式名を保存 |

式(11)の独立した部品の方式名は変更していません。
既存のJSON形式は維持していますが、新規のネイティブLV結果の方式名・丸め末尾・残差計算が変わります。
古い保存結果は旧バージョンの記録として読み込めます。新しい実装・バイナリでは、古いチェックポイントの同一性は成立しません。

## 初期時刻だけを変える独立検証

明示入力されたローカル・ボラティリティ格子の初期行だけを変化させ、同じ乱数による価格差分と報告残差を比較しました。
正の時刻のローカル格子、IV格子、乱数シード、パス数は固定しています。
これはローカル格子の微分を調べる診断であり、市場IVの変動や論文VegaKTの代替ではありません。

[固定した検証条件](../../fixtures/backtesting/allocation-probe-policy-v0.1.json):
3シード、時間区間2/4/8/16、独立サンプリング単位4,096、Strike節点17、ボラティリティ変動幅0.00001/0.00005。
許容差は絶対値0.0000001と相対値0.5%の和です。48項目すべて合格しました。

シード7、変動幅0.00001の場合:

| 時間区間数 | 初期行の価格差分による感応度 | 報告残差 |
| ---: | ---: | ---: |
| 2 | 11.5259340896 | 11.5259340896 |
| 4 | 5.7158692718 | 5.7158692718 |
| 8 | 2.8318658506 | 2.8318658506 |
| 16 | 1.4962018281 | 1.4962018282 |

全条件の最大絶対差は0.00210201で、宣言した許容差内です。
前回の基準ケースに残る約12%の不足を、初期時刻の除外により説明できました。
その不足を任意の市場バケットに加える変更は行っていません。

## 残る条件

ガンマ復元・伝播と市場IVへの配賦を接続し、初期時刻の取り扱いをその導出に沿って決める必要があります。
参照論文は Adrien et al., [Vega KT for the Local Volatility Model: An AD Approach](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4107770) です。
今回、SSRNの本文取得は403で失敗し、出版社の公開ページも購読案内まででした。
リポジトリの計算仕様には式(11)と遷移積分の部品がありますが、式(3)–(5)から式(9)へ接続する全定義は含まれていません。
本文の式を照合するため、閲覧できるPDFまたは保存先を確認中です。

また、現在の集約結果の `active_domain` と除外確率は最終の報告満期の情報であり、全時刻の領域情報ではありません。
解析的密度の元となる曲面情報の保持、非平坦な曲面、満期・Strikeへの感応度の局在、時間・空間格子の収束も継続課題です。
バックテストの通常利用を止めるガードは維持しています。
