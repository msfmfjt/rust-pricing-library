## 市場ショックの定義

市場格子のlog-IV hatを細かい報告格子へ評価した行列をHとする。
報告格子のIV変化は `delta_IV_reporting = H * delta_IV_market`。
価格微分は次のように変換する。

```text
market_risk       = H^T * reporting_risk
market_hedge_matrix = H^T * reporting_hedge_matrix
market_covariance = H^T * reporting_covariance * H
market_price_covariance = H^T * reporting_price_covariance
```

Vegaは価格の微分なので、バケット値自体を補間する操作とは異なる。
この変換で任意の市場ショックに対する一次価格変化を保存する。
raw単位は通貨/absolute volatility、既存ソルバーの0.01換算、数量制約、リッジ、
取引コスト・回転ペナルティは維持する。

現時点で受け入れるのは、同一評価日・同一期日列・同一座標・同一手法・同一単位、
同じ端点範囲を持ち、市場格子の全節点が報告格子にもある入れ子の格子だけ。
同じ原資産・forward・市場状態で使う。異なる市場間の座標変換や期日補間は行わない。
市場の折れ点が報告格子にないと同じhatを正確に表せないため、非入れ子の格子はエラー。

標本共分散には全行列を要求し、対称性・半正定値性を検証する。
限界分散だけから相関を推測しない。価格共分散も同じHで変換する。
nativeとの検証では反対変数ペア256組が独立標本単位であり、変換後の標本共分散を
256で割った平均分散から標準誤差を作る。

## 粗いショックに含まれないリスク

市場ショックだけを最小化すると、それ以外の方向へのリスクを見落とせる。
新しい最適化APIは、細格子の残差ベクトル、市場格子の残差ベクトル、直交補空間の
リスク監査を必ず結果に含める。

Hの完全QR分解で、市場ショックの張る空間とそれに直交する空間を分ける。
補空間は差し引きによる桁落ちを避けて直接計算する。指標は報告quote座標での
ユークリッドノルムであり、実測した市場の分散・共分散ではない。
異なる報告格子のこのノルムをそのまま収束判定に使わない。

9節点市場ショックで最適化したK95/K105ヘッジを、33節点の独立ショックで評価すると、
解析リスクの結果は次の通りだった。

| 指標 | 値 |
|---|---:|
| 細格子の残余Vega L2 | 30.9858569590 |
| 市場ショック空間内の残余Vega L2 | 3.8031417158 |
| 市場ショックに直交する残余Vega L2 | 30.7515762941 |
| 補空間でL2が1 vol pointの最悪方向の一次価格変動 | 0.3075157629 |

最後の値は各quoteを一律1 vol point動かす意味ではない。ショック全体のL2を1 vol pointに
そろえた方向ベクトルに対する値である。方向ベクトルも保存し、その方向への独立な
価格差分で感応度30.7515762934を確認した。ヘッジ後もこのリスクがあるため、
格子安定性の通過を「十分にヘッジできた」とは解釈しない。

## APIと実行

```python
from rust_pricing_backtest.market_shocks import MarketShockMap, solve_market_hedge

shocks = MarketShockMap(reporting_basis, market_basis)
result = solve_market_hedge(
    shocks, raw_target, raw_hedge_matrix, previous, lower, upper, costs,
    ridge=0.0001, tolerance=1e-10,
)
quantities = result.solution.quantities
unmodeled_risk = result.complement
```

これは明示的な市場ショックで最適化する再利用可能なAPI。
既存の日次バックテストの既定目的関数・保存形式・受入ガードは変更していない。
市場ショックを日次運用へ採用する際は、その定義と更新方法を入力・manifestへ持たせる
作業が別途必要。native adapterは引き続き `diagnostic_only=True` を要求する。

```shell
python -m rust_pricing_backtest.market_shock_numerics \
  --policy fixtures/backtesting/market-shock-policy-v0.2.json \
  --output benchmark-results/vega-kt-market-shocks/v0.2
```

旧CLIは引き続き6件失敗・終了コード1。CIにも別ステップとして追加し、旧失敗を無視する
