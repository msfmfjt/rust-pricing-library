# VegaKT バックテストの共通numeraire・割引後誤差検証 v0.1

日付: 2026-10-03  
状態: 共通基準口座による割引後指標の機能検証は合格。論文VegaKTの数値受入は未合格。

## 変更した動作

[要件定義](../vega-kt-hedging-backtest-requirements-v0.1.md)のPNL-03に対応する、
共通money-market accountによる割引後純資産・日次損益・累積損益・最終ヘッジ誤差を追加しました。
通常の現金台帳と損益は引き続き保持します。

`BacktestConfig.numeraire_id` で口座を選び、各snapshotに `NumeraireObservation` を入力します。
口座ID、通貨ID、評価日、正の有限な口座価値、観測・利用可能時刻、出所と版を保存します。
口座が未指定の場合は、割引後の指標をnullとします。
貸出／借入の資金調達金利や未収未払の支払日割引係数から、基準口座を推測しません。

選択した口座の値が欠損している日、口座ID・通貨・評価日が不一致の日、
利用可能時刻が未来の日、観測が古い日は、そのsnapshotを処理する前に停止します。
鮮度には既存の `max_quote_age_seconds` を用います。
供給された口座データは、割引後表示を無効にした場合もproviderへの引渡し前に検査します。

負金利では口座価値が低下し得るため、単調増加は要求しません。
開始値が1以外でも、その尺度を保ちます。途中で基準を置き換えず、
同じ定義で積み上げた口座系列を入力する必要があります。
入力元が表明する出所・版を記録しますが、それだけで外部系列の経済的な正当性を認定するものではありません。

## 計算と台帳照合

`E_initial` は初回取得前の `initial_cash`、`B_initial` は初回snapshotの基準口座価値です。
外部資金移動は未対応です。

```text
割引後純資産_t = E_t / B_t
割引後日次損益_t = E_t / B_t − E_previous / B_previous
割引後累積損益_t = E_t / B_t − E_initial / B_initial
```

最初の行のpreviousは、取得前の初期現金と初回の基準口座価値です。
初期手数料や取得値と時価の差は初日損益に一度だけ含めます。
未収未払の現在価値も `E_t` に含まれており、支払やヘッジ売買を再度控除しません。
金額の単位は、ポートフォリオ価値を入力された基準口座の一単位で測ったものです。

最終ヘッジ誤差は、完走して全建玉・未収未払・現物を精算した場合だけ表示します。
途中停止・失敗・未精算ではnullとします。確定した日がない場合は割引後summary全体をnullにします。

通常の損益内訳から、別経路でも次を計算します。

```text
当日の口座価値による換算損益 = 通常の損益寄与合計 / B_t
基準口座変化による寄与 = E_previous / B_t − E_previous / B_previous
割引後寄与合計 = 上記2項目の和
```

この合計と累積合計を、割引後台帳へ照合します。
通常の損益を割るだけで済ませたり、不一致を寄与へ押し込んだりしません。
基準口座変化による寄与は測定単位の変化であり、追加の現金費用ではありません。

日次許容差は、通常損益の照合許容差を `B_t` で割った値に
`1e-10 + 1e-12 × scale` を加えたものです。
scaleは、1、当日の割引後純資産絶対額、前日の純資産を前日・当日の口座価値で
それぞれ割った絶対額の最大値です。累積許容差は日次許容差の和です。
方式・許容差はmanifestに固定し、実際の差額と許容差を出力へ残します。
これは丸め誤差への対処であり、VegaKTの数値受入基準ではありません。

非有限な換算は `nonfinite_discounted_pnl`、照合不一致は `discounted_pnl_reconciliation`
で停止します。約定や損益の確定を含めて当日を巻き戻すため、修正後に二重計上せず再開できます。

## 互換性と残件

入力はversion 4、結果はversion 5です。checkpoint形式はversion 3を維持します。
入力version 1–3は基準口座指定なしとして読み込み、旧結果version 1–4にも対応します。
新入力では `config.numeraire_id` と各snapshotの `numeraire` を必須のキーとし、未使用時はnullを指定します。
旧結果にない割引後指標を読み込み時に捏造しません。
以前の実装のcheckpointは、形式番号が同じでも実装hashが異なるため再利用できません。

実現／未実現の取得原価別表示、外部資金移動、実際の口座系列・市場データの選定、
Greekによる損益説明などは残件です。PNL-03やH0–H4の全体受入を完了したとは扱いません。
リモートCIは実行していません。

VegaKT本体は `diagnostic_only` と `unvalidated` を維持しています。
数値受入パネルは今回再実行していません。
